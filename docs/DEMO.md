# Design and preview notes

Follow the [approved HTML](design-references/sikkim-experiences-prototype.html) and later approved changes: black/red theme, rounded controls, responsive layouts. Explore opens reels; story circles stay in Community.

Travel Essentials replaces the itinerary builder. Keep permits, transport, bookings, help, updates and preparation on separate pages.

API mode uses the backend, including free bookings. Demo mode uses browser-only samples. Community events/chat are still samples; do not present them as live services. Preview listings cannot accept real bookings.
